## 已退役、明确不做与暂缓采用

这三类不能混为一谈：被上游替代的补丁可以删除，用户不需要的功能不应自动恢复，依赖阻塞的功能则仍可在条件满足后重新评估。

### 已退役：由新结构替代

- 旧独立 floating-bar 插件补丁：浮动 bar 已并入官方 `shell/plugins/bar/`，不再维护第二套 bar 实现。
- 旧 bar 尺寸 token 扩展：`icon-font`、`icon-slot`、`icon-canvas`、`status-slot` 等由上游原生提供，不再背重复补丁。
- 旧通知 popupColumn 霜化实现：结构已不存在，改用新通知列的局部霜化，不是永久放弃通知模糊。
- 旧 `omarchy-system-{logout,reboot,shutdown}` 三个脚本：上游改成统一 `omarchy-system`；旧脚本退役不代表新入口的 niri 分流已完成，见下文优先待办。
- 旧 bar 投影、高光和逐项统一圆角的装饰：不要求完整恢复，接受上游新结构。OSD 的旧专用霜化实现未恢复，也不宣称新结构已达到旧视觉效果。

### 明确不自动启用

- Screensaver：保持用户已选择的禁用策略，不因同步源码而重新打开。
- 上游新增的 Kimi、Grok、OpenClaw、T3 Code 等 agent 安装迁移：按既有选择跳过，不因菜单或源码存在而自动安装。
- 与目标机器无关的 N1x、ASUS、aarch64、Limine 等机型/引导方案：不为了追上游而部署到本机。
- Hyprland/uwsm 专属配置迁移：不得直接当作 niri 配置迁移执行。
- 临时免密 sudo：代码存在不等于机制启用；不绕过 root 属主、路径不可写等安全前提来强行适配 dev-link 安装。

### 暂缓：依赖或验收条件不成立

- Qt 6.12 解钉：本机仍为 Qt 6.11.2、Quickshell 0.3.1；此前 MultiEffect 模糊故障尚无本次实测修复证据。上游 palette 语法修复不能当成模糊故障已修复。
- Omasnap、Monologue、Hype、Signed：当前均未安装；既有测试记录为要求 Qt 6.12 符号，Omasnap 另有 Hyprland 依赖。官方源已加入，不应继续把“没配置源”写成当前阻塞原因。
- OWE 动态壁纸/锁屏整组迁移：没有本次 niri 端到端验收证据，不列为已完成，也不贸然恢复已过时的组件结构。

当前 `local-config/omarchy/shell.json` 使用 `jianlongliu.workspaces` 自定义工作区部件，而非上游内置 `omarchy.workspaces`。因此内置部件存在缺陷与当前桌面“看起来能用”并不矛盾；修复前不要把内置部件当成通用可用接口。
